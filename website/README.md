# Solidis website

The documentation site of [Solidis](../README.md), built with Next.js and Tailwind CSS.

Install its dependencies once with `npm install` in this directory, then run these from the repository root:

| Command             | What it does                                             |
| :------------------ | :------------------------------------------------------- |
| `npm run web:dev`   | Starts the development server on <http://localhost:3000> |
| `npm run web:build` | Builds the site for production                           |
| `npm run web:start` | Serves the production build                              |

The pages are in `app/`, the shared components in `components/`, and the English and Korean messages in `i18n/messages/`.
